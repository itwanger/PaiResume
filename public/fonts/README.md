# Resume PDF fonts

`noto-sans-sc-regular.ttf` and `noto-sans-sc-bold.ttf` are static, TrueType-outline subsets of [Noto Sans SC](https://github.com/notofonts/noto-cjk/blob/f8d157532fbfaeda587e826d4cd5b21a49186f7c/Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf). They are instantiated at weights 400 and 700, then subset to the printable Unicode coverage of the previously bundled OTF fonts. The PostScript names and weight metadata were set separately for each output font.

The variable source SHA-256 is `d68bafcb48a2707749396aa12bbbd833cb70401f3a9a689fd2902c7e0d295964`. The license is in [LICENSE](LICENSE).
