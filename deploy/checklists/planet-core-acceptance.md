# 知识星球会员核心功能验收清单

这份清单是知识星球灰度开放的发布门槛。必须使用真实“派聪明”服务号、一个未绑定过 PaiResume 的微信测试身份、真实知识星球邀请码和真实 AI 服务完成；代码测试、二维码截图或接口返回 200 都不能替代完整验收。

验收范围固定为：扫码注册/登录 → 知识星球 VIP 开通 → 简历编辑保存 → 排版导出 → AI 分析。人工精修、会员购买和简历市场分别验收，不得阻塞这组自助功能的核验。

## 验收准备

- [ ] 使用专门测试批次生成一个可核销的 30/90/365 天知识星球邀请码，记录批次、初始名额和操作人；邀请码、领取令牌不得进入截图、URL或日志。
- [ ] 准备一个从未绑定 PaiResume 的微信测试身份，以及一个已注册但非 VIP 的负向测试账号。
- [ ] 确认 PaiResume 与 paicoding 使用相同的独立桥接密钥、场景前缀和真实服务号 AppID；PaiResume 回调地址为生产 HTTPS 地址。
- [ ] 确认生产 AI 服务商、分析模型、隐私披露和请求超时配置均为真实值。

## 派聪明扫码注册与登录

- [ ] 未登录访问 `/login`，确认协议前不创建二维码；确认协议后生成 5 分钟临时二维码，二维码属于“派聪明”服务号。
- [ ] 用未关注身份扫码并完成关注，PaiResume 收到可信事件后只创建一个用户；账号保存微信身份，不生成占位邮箱或可登录密码。
- [ ] 用已关注但未绑定身份扫码，能够直接注册并登录；重复回调、刷新页面和重复换票均不会创建第二个账号。
- [ ] 登录成功后刷新页面仍能恢复会话；刷新令牌 Cookie 为 `Secure`、`HttpOnly`、`SameSite=Strict`。
- [ ] 过期二维码、旧二维码、错误 poll token、错误签名、超时签名和重复 nonce 均失败，且响应与日志不泄露 openid、领取令牌或桥接密钥。

## 知识星球 VIP 开通

- [ ] 未登录用户在 `/vip/claim` 输入邀请码时只创建短期领取凭证，不占用名额；随后扫码登录并确认当前协议。
- [ ] 登录完成后在同一业务事务中核销一次邀请码并开通 VIP；用户状态为 `ACTIVE`，到期时间与批次权益一致，批次剩余名额只减少一次。
- [ ] 同一个完成请求重复发送不会重复核销；同一账号再次领取、过期/作废/耗尽邀请码均失败。
- [ ] 如果扫码登录成功但领取绑定失败，用户仍能登录，并可重新输入原邀请码直接为当前账号兑换。

## 简历编辑与保存

- [ ] 新建一份测试简历，依次编辑基本信息、教育背景、项目经历和专业技能；页面显示已保存后刷新，全部内容一致。
- [ ] 在防抖保存尚未触发时切换模块、进入排版导出、进入 AI 分析、关闭标签页并重新打开，最后一次修改均已保存。
- [ ] 网络失败时页面明确显示保存失败，不允许带着未保存内容静默进入导出或 AI 分析。
- [ ] 账号 A 无法读取、修改、预览或导出账号 B 的简历。

## 排版导出

- [ ] 标准 PDF 与智能一页各导出一次，文件可打开，中文字体正常，核心模块内容完整，照片访问正常。
- [ ] 导出前会等待当前简历的自动保存完成；PDF 内容与刷新后的服务端数据一致。
- [ ] 浏览器直接生成并下载 PDF；网络记录中没有服务端 PDF 渲染请求，生产主机没有生成本地 PDF 文件。
- [ ] 非 VIP 账号同样可以使用排版导出和智能一页，不出现会员拦截。

## AI 分析

- [ ] 刚领取成功的知识星球 VIP 可以进入 AI 分析，选择求职场景后收到流式状态、评分、问题和建议；刷新后能读取最近一次成功结果。
- [ ] AI 分析使用后台当前启用的分析模型和场景提示词，成功与失败记录均关联当前用户和当前简历。
- [ ] 非 VIP 账号调用普通、流式和最近结果接口都被服务端拒绝，不能只依靠前端隐藏入口。
- [ ] AI 上游超时、限流或返回异常时，页面给出可重试错误，不记录简历原文或模型完整返回。

## 发布确认

- [ ] 验收后清理测试简历和不再需要的测试数据，但保留必要的审计记录。
