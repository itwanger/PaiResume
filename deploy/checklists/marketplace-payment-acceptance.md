# 用户简历市场上线验收清单

本清单只在会员支付已稳定运行、内容治理有人值守后执行。必须使用隔离测试账号、已审核的低价测试简历和可真实退款的小额微信订单，保存平台订单号、微信交易号、内容版本、时间与操作人。

## 内容与权限

- [ ] 新投稿和修改版本均先进入待审；旧的已审核版本在新版本通过前继续正常展示。
- [ ] 驳回、平台下架、恢复、举报处理和创作者申诉均要求理由并写入不可覆盖的审计记录。
- [ ] 作者只能管理自己的条目与申诉；买家、作者、管理员和未购买用户的正文权限分别符合预期。
- [ ] 免费内容只返回作者明确公开且已审核的版本；付费内容在服务端确认权益前不返回正文。
- [ ] 举报/侵权投诉的联系方式只在后台可见，来源 IP 只保存摘要，重复提交和频率限制有效。

## 支付、版本与退款

- [ ] 市场开关关闭时不能发布或创建新订单，但历史买家仍能查看已购版本，回调与对账仍继续。
- [ ] 创建 Native 订单后，金额、卖家、买家、条目和不可变版本快照与微信侧完全一致。
- [ ] 回调、主动查单、超时关单、重复通知和跨节点对账均只落账一次；二维码过期后不再返回。
- [ ] 下架、转免费、换版或注销触发销售截止；截止后的迟到付款进入人工退款处置，不新增作者收益。
- [ ] 全额退款在微信商户平台真实完成后，平台确认接口原子撤销买家权益并反冲冻结/可用/已结算收益；部分退款不会被误当作全额退款。
- [ ] 同一买家重复付款、已撤销权益后再次付款、历史订单丢回调等异常均进入正确复核队列并触发值班告警。

## 作者收益与运营值守

- [ ] 作者收益先冻结，观察期结束且取得晚于冻结截止点的微信 `PAID` 主动查询结果后才转为可用。
- [ ] 作者申请结算、管理员线下转账登记、流水备注和审计记录可完整追踪；接口不会伪装成自动提现。
- [ ] 已结算收益退款后正确形成反冲或待抵扣欠款，后续收益优先抵扣，钱包不会出现负数。
- [ ] 管理员已排定投稿、举报、申诉、退款、对账失败和作者结算的值班人、响应时限与升级渠道。
- [ ] 真实客服邮箱可收发订单材料，隐私、服务、退款和 AI 第三方披露与当前页面完全一致。

以上全部完成并留存证据后，才可设置 `MARKETPLACE_ENABLED=true` 与 `MARKETPLACE_PAYMENT_ACCEPT_NEW_ORDERS=true`。
