# 人工精修生产验收清单

本清单必须在隔离的预发布域名、测试账号和真实 SMTP 收件箱下完成；加急支付还需要真实微信商户。人工精修不设置业务开关，正式发布前必须完成会员门槛、PDF 附件投递和队列状态验收。

## PDF 选择与直接邮件

- 普通排队选择本地 PDF 后，前端只创建包含文件名、大小和 SHA-256 的申请记录；网络记录中没有人工精修 OSS 请求。
- 点击发送时使用 `multipart/form-data` 提交原 PDF。服务端复核文件名、大小、MIME、`%PDF-` 文件头和 SHA-256，任一不一致都拒绝。
- 服务端只在内存中处理 PDF，不写应用目录、临时目录或对象存储。Spring multipart 上限为单文件 10 MiB，请求 11 MiB，文件阈值 10 MiB。
- 附件只发送到 admin 配置的人工精修收件箱，邮件 `Reply-To` 是申请人已验证的联系邮箱。
- SMTP 接受前申请保持 `EMAIL_PENDING`，不进入公开队列；SMTP 接受后一次性写入 `dispatched_at` 和 `queued_at`，状态变为 `EMAILED`。
- 邮件投递失败时事务回滚，用户重新选择同一份 PDF 后可再次发送；不会因刷新页面而丢失已支付的加急申请。

## 会员与加急

- 非会员可看到公开队列，申请区只显示成为派简历会员的入口，无法创建申请。
- 有效会员选择普通排队时不下单、不显示付款码，PDF 发送成功后进入队尾。
- 只有选择加急时创建加急订单；预设金额和自定义金额都需校验上限。支付确认前拒绝发送 PDF。
- 刷新页面后，已付费但未发送的用户需要重新选择申请时的同一份 PDF；文件名、大小或 SHA-256 不同时拒绝。
- 公开队列中，已接单项优先保持处理；等待项按加急金额从高到低排列，同金额按付款时间，普通排队按入队时间。

## Admin 与隐私

- Admin 可修改人工精修收件邮箱，修改后下一封邮件直接投递到新地址，无需重启。
- Admin 可标记接单、已精修、退回和退款确认；已付费申请退回时必须先进入退款复核。
- 公开队列只显示脱敏申请号、队列状态、加急标记、金额和时间，不显示姓名、邮箱、简历内容或原文件名。
- 日志不记录 PDF 字节、简历正文或完整邮箱。已被邮件系统接受的副本无法由平台远程召回，该边界已在隐私政策和服务条款中告知。

免费排队项目均有申请号、邮件头、SMTP 接受记录和入队时间后，才可开放人工精修。加急项目还需要订单号、商户平台截图和退款记录，完成后才可设置 `RESUME_REVIEW_PAYMENT_ACCEPTANCE_CONFIRMED=true`。
