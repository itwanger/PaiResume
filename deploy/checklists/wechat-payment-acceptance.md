# 微信支付上线验收清单

真实商户验收必须在隔离测试账号和可退款的小额商品上进行，保存平台订单号、微信交易号、时间和操作人。代码测试或模拟支付不能替代本清单。

- [ ] 支付开关关闭时不能创建新订单，但历史订单查询、回调和对账仍正常。
- [ ] 会员订单创建、二维码展示、支付回调、主动查单和权益发放金额一致且只执行一次。
- [ ] 未支付订单到期前查单、关单、再次查单，最终状态正确。
- [ ] 关单前后发生迟到支付时：没有更晚成交单则幂等补发本单权益；已有更晚 `PAID` 替代单才进入人工退款队列，且不重复发放权益。
- [ ] 相同回调、相同幂等键和相同微信交易号重复到达时不重复入账。
- [ ] 商户号、应用号、币种、金额、签名、证书序列号任一不匹配时均拒绝处理并产生告警。
- [ ] 管理员登记退款处理中，随后填写真实退款单号确认退款；审计记录不可覆盖。
- [ ] 用户端能看到可理解的处理状态、订单号、退款规则和客服入口。
- [ ] 连续对账失败、长时间待支付、重复付款和待退款均能通知到值班人。
- [ ] 会员支付验收完成后只打开会员开关；用户市场仍保持关闭。
